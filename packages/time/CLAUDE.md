# Forma Time (`packages/time`)

形·时：在地图上给每个点画回家的路线。只看地图时，路线交叉会不会相撞全靠试；把时间立起来作为第三维，每条路线就是一根世界线，相撞就是两线相交，等待就是竖直的一段。

## 规则

- 每个点每拍走一格或原地等待；到达终点后停在那里（仍会挡路）。
- 相撞：同一拍同一格，或相邻两点在同一拍互换位置（穿过彼此）；三点及以上轮转不算相撞。巡逻机按固定循环移动，与点同样会相撞。
- 所有点必须在天花板 `ticks` 之前到家；分数为等待总数，`par` 为最少等待。
- 路线是不重复经过同一格的路径：拖回上一格即撤销一步。

## 代码导航

- 模型（`src/model/`，纯函数）：
  - `board.ts`：地图（`.` 地面、`#` 墙、空格为板外）、邻接、巡逻机循环（`U D L R W`）、单点最短距离。
  - `plan.ts`：路线 `Route`（经过的格子与每格等待数）、`timeline`（每拍位置）、`evaluate`（相撞、到达、是否过关）、`drawTo`（画线 / 撤销一步）、`addWait`、`stepAt`。
  - `levels.ts`：五章关卡，`ticks` 与 `par` 由测试求解器校验。
- 元素（`src/elements/`）：
  - `scene.ts`：Three.js 时空舞台，同一个场景承载两种视图：`lift = 0` 为俯视地图，`lift = 1` 为时空盒。世界线以"拍"为单位建模、整体按 `lift` 纵向缩放，所以抬升时地图上的路线直接长成世界线；墙在俯视时是实心块、抬升后变成通高的淡玻璃；相撞点在时空中常驻显示，俯视时只在运行到那一拍时出现。手指点选世界线取屏幕上最近的点（24px 内）。
  - `level.ts`：关卡控制：从点拖出画线（经过的格子自动补齐）、从路线末端继续画；俯视时点路线、时空中点世界线 = 在那一步多等一拍；Run 以时间平面扫过播放，遇到第一次相撞即停；倾斜 / 按钮抬升时间。
  - `hero.ts`：标题页三点绕环的三螺旋。
- `game.ts`：章节、定理卡挂载点与图标。

## 章节

I Now（只有俯视）→ II Then（开放抬升时间，首次抬升解锁 Worldlines）→ III Narrow（单行道与让行湾）→ IV Patrol（巡逻机在时空中是固定的折线墙）→ V Form（终章地图为"形"：开 是相连的街道，彡 的三笔各是一条独立车道）。

## 测试

- `test/plan.test.ts`：时间线、互换相撞、轮转不相撞、画线撤销、巡逻机。
- `test/levels.test.ts`：用 `test/solver.ts`（按连通块拆分的联合 BFS，路线不重复经过格子，与玩家能画的完全一致）校验每关在 `ticks` 内可解且最少等待恰为 `par`，解出的路线再经 `evaluate` 回放无相撞；第二章起天花板收紧（少一拍就无解或更贵）；巡逻循环在地面上且闭合。
